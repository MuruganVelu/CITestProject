# CITestProject

Existing TestNG/Selenium suite lives in `MavenAutoTest/`.

**Use Case 3 (AI-based induction & knowledge documentation)** is a Java Spring Boot agent in [`knowledge-agent/`](knowledge-agent/README.md). It ingests uploaded Jira stories plus a 50-case internet-banking regression master and generates onboarding Markdown. LLM backend is GitHub Models (GitHub token), with a heuristic fallback.
